# Security policy

HAVEN is an unreviewed engineering implementation. Production and emergency use remain blocked; see [SECURITY_STATUS.md](SECURITY_STATUS.md).

Please report suspected vulnerabilities using this repository's **Security → Report a vulnerability** private reporting facility once the owner enables it. If private reporting is unavailable, contact the repository owner privately before sharing exploit details. Do not attach real messages, passwords, invitation tokens, recovery kits or private keys to a public issue.

The repository owner should enable private vulnerability reporting, secret scanning and push protection, dependency alerts, and require the Repository security workflow on protected branches. Availability varies with GitHub plan and repository visibility. No hosted settings have been changed by this local preparation.

Only the current reviewed source is maintained. Dependency scans and automated tests are engineering evidence; independent application/cryptographic review and physical-device qualification remain required.
