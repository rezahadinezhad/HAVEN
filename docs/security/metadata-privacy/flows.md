# Metadata inventory: flows and graph reconstruction

Read with the field-level [CSV](inventory.csv). Every category below is classified for this checkout, including data that never becomes a Django row. Runtime/DB administrators can bypass application-level authorization; API scope is not protection against A4.

## All graph-bearing paths

A1 joins User→Device→Membership→Conversation and MessageEnvelope.sender_device. It also reconstructs these edges from signed genesis and header/transition JSON even if relational copies disappear. CryptoControlEvent.Welcome targets, live KeyPackage owner/claimant links, DeliveryCursor, upload owner/conversation, view-once account ledger, notification→envelope and account-keyed StorageUsage add independent evidence. Audit actor/target and historical backups can reconnect deleted temporary links. Stable BasicCredential contains user/device UUIDs. UUID opacity prevents simple enumeration, not correlation after disclosure.

A3/A4 add cookie→account, account→WebSocket channel, submission/retrieval timing, lookup/claim requests, IP at login ingress and live media access. Restoring an old dump adds removed links/times; deleting them in current PostgreSQL cannot revoke copies. No routing change here obscures those fundamental edges.

## Existing protections, not newly implemented

E2EE/worker key custody, TLS/CSP/local assets, encrypted atomic vault, replay/epoch/roster/chain verification, durable-before-ACK, storage budgets, optional activity defaults, generic sync hints, source-isolated login, JSON cache decoder, absence of raw IP models/login audit, proxy/PG log suppression, original retention and backup controls all precede this change. Only changes specifically identified as new above belong to this initiative's improvement claims.
