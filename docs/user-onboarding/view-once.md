# Send a photo or video for one viewing

In an unlocked conversation with recipients, enable **View once photos and videos**, then choose the photo/video using the attachment button. The file is sent with that mode. Turn the option off for ordinary repeatable attachments. Files remain limited to 25 MiB; supported video codecs depend on the recipient's browser.

A recipient taps **Open photo once** or **Open video once**. Each person has one viewing session across all their devices. In a group, every recipient present when upload starts gets their own session. The sender sees a sent placeholder and cannot reopen it inside HAVEN.

Opening consumes the session before the file loads. Stay online to load it: interrupted loading, decoding failure, reload or a crash may use up the opening without showing the media. Closing the viewer, leaving/hiding the tab, locking HAVEN or finishing the video closes it permanently. A session is capped at ten minutes including loading. There is no offline replay or resumable recipient download for this mode.

After opening, the message shows **Opened**. HAVEN offers no save, download or forwarding action for it, and new history/recovery exports exclude it. New imports do not restore historical view-once items.

**Recipients can still capture the screen or use another camera or a modified client.** HAVEN cannot guarantee physical erasure of all copies or browser/backup memory. The server records opening access to enforce the limit even when optional read receipts are off. This is a privacy convenience within HAVEN, not protection against an untrusted recipient.

Physical iOS/Android behavior, codec compatibility and independent security review remain unqualified. The project's overall security release gate remains closed; the loopback integration is for evaluation.
