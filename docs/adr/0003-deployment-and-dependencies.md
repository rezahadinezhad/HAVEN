# ADR 0003 — transport, PKI, dependencies and deployment limits

Django 5.2.18 supported LTS, DRF 3.18.3, Channels 4.3.2, channels-redis 4.3.0, Uvicorn 0.54.0, Python 3.12.15; Next 16.4.3 and React 19.3.1 on Node 24.18.0. Exact resolved packages/hashes in uv.lock, requirements.lock, package-lock.json and Cargo.lock. Initial audit found older constrained DRF/cryptography vulnerable; upgraded to DRF 3.18.3 and cryptography 50.0.2. Daphne moved to development-only because Twisted's IMAP advisory remains flagged; no IMAP component is exposed, and production Uvicorn removes Twisted entirely. Do not suppress the development finding or call the whole toolchain vulnerability-free.

Opaque 384-bit random session identifiers are stored as SHA-256 hashes, expire in 12h, Secure/HttpOnly/SameSite=Strict __Host cookies. CSRF cookie is readable by design; server validates token plus exact Origin. Argon2id password hash: 64MiB, 3 passes, one lane. DB sessions are authoritative; Redis unavailability fails rate-limited writes closed while existing authenticated HTTP delta sync remains available.

Nginx is the sole externally published service, TLS 1.2/1.3, no HTTP listener, exact backend Host/Origin validation. Proxy's forwarded-proto header is trusted only across the private Docker network. Containers on this network are a trusted boundary; exposing API port would break that assumption. Runtime API/web have no external network route in Compose. No telemetry/CDN/provider login/push services. Development TLS proxy is test-only; it is not the production proxy.

Public IP certs: Let's Encrypt IP certificates are 160h per its 2026-01-15 announcement. CA/B baseline maximum is not a provider lifetime. Public renewals need issuer connectivity and eventually fail in isolation. Private PKI root belongs on isolated signing workstation; leaf/IP trust must be manually installed/verified ahead of outage. A separate leaf/full chain and protected intermediate signing ceremony are required for production. Test CA is ephemeral, never a production root.

Single-host Docker Compose is not redundant. Manual failover plan explicitly fences former primary, quantifies async RPO and acknowledges origin-separated IndexedDB. Neither PostgreSQL replication automation nor a safe client-origin migration is qualified. No staging public endpoint, genuine routable IP, external audit, real Iranian reachability or physical mobile trust testing has been supplied.
